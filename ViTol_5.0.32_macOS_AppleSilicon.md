# ViTol 5.0.32

- Отзывы и предложения отправляются из ViTol в раздел «Отзывы» приложения владельца «ViTol Отчёты»; другие способы отправки отзыва из приложения убраны.
- Если сервер отзывов временно недоступен, отправленный отзыв сохраняется локально и передаётся автоматически после восстановления связи.
- В окне связи отдельно указано, получен ли отзыв сервером или ожидает отправки.
- Повторные попытки используют один идентификатор, поэтому временный сбой связи не создаёт дубликаты.

Установочный архив выпуска подготовлен для macOS Apple Silicon.
