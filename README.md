# ViTol для Mac

[Скачать актуальный выпуск ViTol](https://github.com/victormertoncorp-eng/vitol-updates/releases/latest)

[Архив предыдущих версий для Mac — 46 выпусков](https://github.com/victormertoncorp-eng/vitol-updates/blob/main/ARCHIVE.md)

На странице выпуска выберите файл для своего Mac:

- **Apple Silicon (M1 и новее):** файл с `AppleSilicon` в названии.
- **Intel:** файл с `Intel` в названии. Если его нет в выбранном выпуске, эта версия для Intel пока не опубликована.
- **Автономная установка:** файл `_Offline.pkg` содержит всё приложение и не скачивает его во время установки.
- **Ручная установка:** распакуйте `.zip` и перенесите `ViTol.app` в папку «Программы».

Перед заменой приложения сохраните документы и полностью завершите ViTol через ⌘Q. Установщик проверяет совместимость с процессором и минимальную версию macOS. Сетевой установщик **5.0.27** устарел; для новых установок выбирайте актуальный автономный пакет или ZIP.

Публичные тестовые сборки пока не подписаны сертификатом Apple Developer ID и не нотарифицированы Apple. macOS может блокировать установку или запуск. Подпись канала Sparkle проверяет целостность обновления и не заменяет подпись Developer ID. Подробнее — [документация Apple](https://developer.apple.com/developer-id/).

Встроенное обновление Sparkle используется на macOS 14 и новее. Для macOS 12–13 доступна ручная установка совместимой сборки; работа на реальных macOS 12–13 пока не проверена.
