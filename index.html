Если тип процессора не определился: меню Apple → «Об этом Mac». Для M1, M2, M3 и новее выберите Apple Silicon; для процессора Intel — Intel.

Установка

  1. Сохраните документы и завершите предыдущую ViTol через ⌘Q.
  2. Скачайте автономный установщик для своего Mac. Все необходимые файлы уже внутри.
  3. Откройте пакет и следуйте подсказкам macOS.

Сборки без Developer ID и нотарификации могут блокироваться macOS. Подпись обновлений Sparkle подтверждает целостность и не заменяет проверку Apple.
