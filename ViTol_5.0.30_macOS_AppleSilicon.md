# ViTol 5.0.30 — тестовые режимы и панель владельца

В ViTol подготовлены режимы Full, Lite, Pro и Promo. Пока владелец не назначил режим конкретной установке, функции сохраняются в прежнем объёме. Просмотр и базовый экспорт доступны в каждом режиме. При истечении срока Promo клиент локально переходит в Lite. Смена режима не блокирует сохранение уже открытого документа.

Владелец получает отдельное macOS-приложение «ViTol Отчёты». Оно показывает проверенные недельные сводки и позволяет выбирать режим и отдельные функции для установки. Запрос проверки обновления заставляет ViTol проверить подписанный канал; скачивание и установка по-прежнему управляются пользователем.

API удалённого назначения опубликован в службе Cloudflare. До первого назначения конкретной установке ViTol продолжает работать с полным набором функций. В режиме без сети приложение не обращается к службе и использует последний сохранённый режим.

Это тестовый механизм разграничения функций, без платежей и подписок. Ограничения интерфейса не защищают от изменения приложения самим пользователем. Тексты отзывов и подробности отдельных сбоев в недельных сводках пока не передаются.
