# ViTol 5.0.35

## Продолжение локальной обработки после сбоя

Конвертация, экспорт, Smart Export, сборка ZIP, локальный OCR и рабочие сценарии сохраняют отдельные частные снимки исходников и параметров. После восстановления сессии незавершённая локальная обработка продолжается. Вновь внесённые правки, язык интерфейса и положение просмотра не заменяются параметрами старой задачи.

Перед публикацией результата сохраняется контрольная запись. После сбоя уже записанный файл проверяется и используется повторно; второй экземпляр не создаётся. Изменённый либо удалённый готовый результат требует действия пользователя. Файлы, которые уже находились в выбранной папке, не перезаписываются: новое имя закрепляется в задаче.

Отмена ожидающей задачи сохраняется между запусками. Для отменённой задачи с удалённым снимком предлагается заново запустить операцию. Печать, облачные отправки и перезапись исходного файла не повторяются автоматически. Зашифрованный документ, которому снова нужен пароль, останавливается с пояснением.

## Скан → редактируемая таблица

Новый сценарий распознаёт таблицы локально на русском и английском. Перед экспортом можно исправить текст ячеек, границы, строки и столбцы. Каждая страница требует проверки. Правки и отметки проверки сохраняются при сбое.

XLSX содержит отдельный лист для каждой страницы и редактируемые текстовые ячейки, включая пустые. CSV сохраняется по страницам с выбранным разделителем. Формулы, оформление и объединения ячеек не реконструируются; таблицы без линий могут потребовать ручного исправления сетки. Для CSV предусмотрена защита от исполнения распознанного текста как формул.

## Уменьшение комплекта PDF

По умолчанию выполняется структурная оптимизация без растрирования страниц и изменения изображений. Дополнительно можно явно выбрать пересжатие поддерживаемых JPEG и проверить размер результата до сохранения копии. Текст, векторные объекты и размеры страниц сохраняются.

Изображения с неподдерживаемыми масками, цветовыми параметрами или метаданными остаются без изменений. Подписанные, зашифрованные и XFA PDF не обрабатываются этим сценарием. Проверка соответствия PDF/A и PDF/X не выполняется. Результат, который не стал меньше исходного файла, не сохраняется.

## ViTol Сервис 1.3.1

Исправлено восстановление загрузки нескольких файлов одного выпуска: проверка готового ZIP больше не удаляет состояние незавершённого установщика. Потерянный ответ после успешной передачи восстанавливается проверкой размера и SHA-256 без повторной загрузки.

При сетевых ошибках действует увеличивающаяся задержка повторов. Ошибки доступа и защитных проверок требуют явного повтора после проверки владельцем. Расписание либо причина ожидания отображается в Сервисе.

## Распространение

macOS Apple Silicon. Автономный установщик содержит приложение. Подпись обновления Sparkle проверяется отдельно. Developer ID и нотарификация Apple пока не выполнены; проверка на чистой macOS и Intel Mac не проводилась.
