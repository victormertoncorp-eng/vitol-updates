# ViTol 5.0.27

Эта версия выпускается отдельно для Mac с Apple Silicon и Intel. Оба варианта собраны с системным минимумом macOS 12. Единый установщик определяет архитектуру компьютера и устанавливает подходящий вариант. Пользовательские документы и настройки находятся вне заменяемого приложения.

Обновления внутри приложения используют отдельные подписанные каналы Sparkle для Apple Silicon и Intel. Встроенный модуль Sparkle собран с минимальной версией macOS 14; на macOS 12–13 обновление через Sparkle недоступно, для него предусмотрен единый установщик. Реальный запуск ViTol на macOS 12–13 пока не проверен на отдельном компьютере.
