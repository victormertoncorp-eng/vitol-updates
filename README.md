# ViTol для Mac

[Скачать единый установщик ViTol 5.0.27](https://github.com/victormertoncorp-eng/vitol-updates/releases/download/v5.0.27/ViTol_5.0.27_Universal_Installer.pkg)

Установщик сам определяет, какой процессор установлен в Mac (Apple Silicon или Intel), и скачивает только подходящую сборку. Для установки нужен интернет и macOS 12 или новее. Если ViTol уже работает, сохраните документы и завершите его через ⌘Q до установки.

[Описание выпуска и отдельные архивы](https://github.com/victormertoncorp-eng/vitol-updates/releases/tag/v5.0.27) · [SHA-256 файлов](ViTol_5.0.27_SHA256.txt)

Встроенное обновление Sparkle используется на macOS 14 и новее. Для macOS 12–13 устанавливайте следующую версию тем же единым установщиком. Работа на реальных macOS 12–13 пока не проверена.

Пакет пока не подписан сертификатом Apple Developer ID и не нотарифицирован Apple. macOS может потребовать дополнительного подтверждения установки. О том, что это означает, см. [документацию Apple](https://developer.apple.com/developer-id/).
